# План работ

Что запланировано и в каком порядке. Сделанное переезжает в product review в
[`architecture.md`](architecture.md).

## 1. Android: дизайн приложения

Главный экран, добавление Mac и привязка — в Material 3 Expressive, вибрация с выключателем
(см. product review в `architecture.md`). Осталось:

- **Настройки** — за шестерёнкой: пока вибрация и диагностика; оформить в том же стиле.
- **Запрос при открытом приложении** — карточка Mac уже показывает «Принять / Отклонить»,
  а уведомление поверх всплывает тоже; всплывать ему стоит, только когда приложение не на экране.
- **Анимации — у каждого действия:** коротко и аккуратно; ничего не появляется и не исчезает
  рывком.
- **Статус Mac сразу после передачи** — на секунды «Не рядом», пока скан не перезапустится.

## 2. Сборки для обычных пользователей

**Mac:** DMG, подписанный Developer ID и нотаризованный, собирает `macos/scripts/release.sh`
(членство Apple Developer активно с 10 октября 2026). Осталось выложить его в GitHub Releases.

- **Окно DMG по-своему:** фон с каплей и стрелкой «перетащите в Программы», LocalDrop слева,
  «Программы» справа, крупные значки, без панели инструментов и боковой панели, свой значок тома.
  Раскладку хранит `.DS_Store` внутри DMG; собирать её `dmgbuild` (пишет файл сам, без
  управления Finder — повторяемо и в скрипте), фон в 1× и 2× для Retina. Фон статичный и не
  следует тёмной теме — подобрать его, чтобы хорошо смотрелся в обеих.

**Android, Google Play:** личный аккаунт Play Console, имя разработчика «Zeppon», отдельная почта
поддержки. Данные на проверке в Google.

- Подпись релизной сборки ключом загрузки (ключ хранит владелец, не репозиторий), сборка AAB,
  Play App Signing.
- Закрытое тестирование: не меньше 12 тестировщиков 14 дней подряд — условие для личного
  аккаунта перед публичным выпуском.
- Декларация фоновой службы `dataSync` с видео, анкета Data safety (ничего не собираем),
  политика конфиденциальности на GitHub Pages.
- Страница в магазине на русском и английском; снимки экрана — после редизайна (п. 1).
- Подписанный APK также в GitHub Releases.

## 3. Проверки

- Android 10 (minSdk 29, с 9 октября 2026): на эмуляторе или устройстве — запись в «Загрузки»,
  BLE-скан с геолокацией, пробуждение приложения по сигналу Mac, уведомления.

- Перетаскивание фото прямо из «Фото» на панель у края экрана Mac — проверить на устройстве.
- После ночи: Mac больше не перечитывает сеть в коротких ночных пробуждениях.
